## Описание игры

### Правила игры
- Игроки по очереди ставят на свободные клетки поля 3×3 свой знак (X или O).
- Первый ход делает игрок за «X».
- Побеждает тот, кто первым выстроит в ряд (по горизонтали, вертикали или диагонали) три своих знака.
- Если все 9 клеток заполнены, а победитель не выявлен — объявляется ничья.

### Логика победы/поражения
Победа определяется после каждого хода. Проверяются 8 выигрышных комбинаций:
- 3 горизонтали
- 3 вертикали
- 2 диагонали

Если ни одна комбинация не собрана и остались пустые клетки — игра продолжается.

### Особенности реализации
- Игра полностью написана на чистом JavaScript без использования библиотек.
- Используется Grid Layout для создания игрового поля 3×3.
- После завершения игры (победа или ничья) клетки становятся неактивными.

### Как определяется победитель?
Функция `checkWinner()` перебирает массив `winningCombinations`, сравнивая значения в ячейках `board`. Если все три значения в комбинации равны и не пустые — объявляется победитель.

### Как обрабатываются клики?
При клике на клетку:
1. Проверяется, активна ли игра и свободна ли клетка.
2. В клетку записывается символ текущего игрока.
3. Проверяется победа или ничья.
4. Если игра продолжается — переключается игрок.

### Как работает перезапуск?
Кнопка «Начать заново» вызывает функцию `restartGame()`, которая:
- Очищает массив `board`
- Сбрасывает `currentPlayer` на «X»
- Устанавливает `gameActive = true`
- Очищает все клетки на странице
